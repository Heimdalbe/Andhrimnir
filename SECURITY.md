# Beveiligingsbeleid

Andhrímnir bewaart persoonsgegevens en tegoeden van LAN-deelnemers.
Een beveiligingsprobleem nemen we dus ernstig.

## Ondersteunde versies

| Branch | Ondersteund |
|---|---|
| `Prod` | ✅ |
| `ACC` | ✅ |
| `dev` | ⚠️ Alleen tijdens ontwikkeling |

## Een kwetsbaarheid melden

**Meld een beveiligingsprobleem nooit via een publiek issue of een pull request.** De repository is publiek; iedereen zou het probleem dan kunnen misbruiken voor het opgelost is.

Meld het op een van deze manieren:

1. **Via GitHub (voorkeur):** tab **Security** → **Report a vulnerability**. Alleen de beheerders zien je melding.
2. **Persoonlijk:** contacteer **Seppe Landtsheer** of de **ICT** via een privébericht.

Vermeld in je melding:

- welk onderdeel (API, gebruikers-, keuken- of kassafrontend, database);
- de stappen om het probleem te reproduceren;
- wat een aanvaller ermee zou kunnen doen (bv. tegoed aanpassen, gegevens van anderen bekijken).

## Wat je mag verwachten

- Een eerste reactie binnen **7 dagen**.
- We houden je op de hoogte tot het probleem opgelost is.
- Na de oplossing vermelden we je graag als melder, als je dat wilt.

## Wat we vragen

- Test alleen op je **eigen lokale omgeving** of de testomgeving, nooit op de productieomgeving tijdens de LAN.
- Bekijk, wijzig of verwijder geen gegevens van andere gebruikers.
- Deel het probleem niet met anderen tot het opgelost is.
